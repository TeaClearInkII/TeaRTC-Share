证书（CA）安装引导

当前证书未受信任：只能看页面，无法连接服务器（成员 / 聊天 / 共享均不可用）。

CA 是什么：本服务自建证书签发机构。安装后浏览器信任本服务证书——页面无警告、WebSocket 正常连接（成员 / 聊天 / 共享可用）、麦克风 / 摄像头权限正常。

安装步骤（任选其一）：

· 方式一（推荐）：点击「复制一键命令」→ 打开 PowerShell 粘贴回车（自动下载并安装）。
· 方式二（手动）：点击「下载 CA 证书」→ 双击 ca.crt → 安装证书 → 存储位置选「受信任的根证书颁发机构」→ 完成。

安装完成后：完全关闭浏览器重新打开本页面。

证书（CA）引导

    
本服务使用自建 CA 签发 HTTPS 证书。首次访问时浏览器提示"证书不受信任"：下载 CA 并安装到「受信任的根证书颁发机构」后完全关闭浏览器重开；或复制一键命令在 PowerShell 执行：

    

    

      下载 CA 证书
      
    

    
急着观看可先点「高级 → 继续前往」，但共享端在证书未受信时无法采集屏幕。

  






  

    
清晰度设置

    
目标编码参数（观看者按档位接收：流畅/高清/超清），共享中修改即时生效。

    

      
      
      
      
    

    
高帧率会分摊码率，追求单帧清晰度建议 24/30fps；H.264 优先硬件编码（游戏/视频场景大幅降低 CPU 占用），VP8 兼容最广。该编码设置仅应用于屏幕共享；摄像头固定使用 VP8；屏幕共享中切换需重新选择窗口/屏幕。
