## 一、功能设计

### 1. 总体架构：mesh 全互联 + SFU 代理转发

每台运行服务的电脑 = 一个**节点**（随机 nodeId，如 `82add983`）。节点间建立两条通道：

- **信令通道（node-ws，TCP 7553）**：握手（node-hello 交换 nodeId/本机服务地址/主机名）、
  用户列表同步（node-peers/peer-add/peer-remove）、聊天与文件跨节点转发、订阅指令
  （node-subscribe/unsubscribe）、拓扑广播（node-topo）、延迟测量（node-ping/pong）、
  mesh 自动扩展（sendNeighbors + forwardToken）。
- **媒体通道（节点间 WebRTC）**：双向全量互转。发起方（initiator）创建 PC 并协商
  （CreateOffer/CreateAnswer/candidate 经 node-ws 交换），预置 recvonly transceiver
  保证初始 offer 含 m-line。

### 2. 按需转发（核心机制）

- 本节点有观看者 → 向所有邻居发 `node-subscribe` → 邻居转发**全部本地流**
  （simulcast 三层 + 音频通道）过来。
- 对方流到达 → 本节点注册为**代理流**（流 id 加对端节点前缀 `对方节点id:用户id`）
  → 广播 `stream-added` → 本地观看者经 SFU 订阅代理流。
- 无观看者 → `node-unsubscribe` → 停止转发并清理代理流（省带宽）。
- 只转发**本地流**（代理流不回传，防回环递归——曾因全量路径未过滤导致代理流 ID
  无限叠加 `82add983:a94e6274:82add983:...:u3` 压垮连接）。

### 3. 跨网络可达性

- 两端有公网 IPv6 → host 直连（Windows 程序规则 `TeaShare-app` 放行 exe 全端口入站）。
- 不行 → TURN over TCP（3478）+ UDP 中继兜底（曾用固定段 49152-49200，后因与
  Windows 动态端口保留段冲突改回随机端口）。
- 节点间 ICE 需保活：pion 默认 KeepaliveInterval=0（无媒体流量 5s 即 disconnected），
  无共享流时节点间连接会断开（曾计划加 keepalive，未落地即决定移除）。

## 三、修复历程（2026-08-22 当天排查链）

1. **互联地址端口错误**（分享列表对方主机端口显示为 WS 临时源端口如 53479）
   → 握手交换本机服务地址（node-hello 带 `addr`），nodeInfoList 优先下发握手地址。
2. **浏览端穿透访问卡片 IP 显示**（樱花/ngrok 隧道转发，服务器看到 127.0.0.1）
   → 前端判断 enterHost 为域名时卡片 IP 显示"穿透域名访问"。
3. **跨网络媒体完全不通**（卡片/用户同步正常但无画面）
   → 防火墙 UDP 入站未放行：程序规则 `TeaShare-app`（放行 exe 全端口）+ 端口规则，
   netsh 同步执行（先删后加，避免竞态）。
4. **TURN 中继端口 bind 失败**（固定段 49152-49200 与 Windows 动态端口保留段冲突）
   → 中继改回随机端口（程序规则已覆盖入站）。
5. **节点间 ICE 永不开始**（offer 为空 SDP，对端 SetRemoteDescription 拒绝）
   → 预置 recvonly transceiver 保证 offer 含 m-line。
6. **代理流 ID 无限递归**（双向互订阅全量转发未过滤代理流 → 连接崩溃、拓扑变空）
   → subscribeAllLocal/initNodePCLocked 全量转发加 isProxyStream 过滤。
7. **流停止后节点间连接断开**（pion 默认无 ICE keepalive，无轨 5s 后 disconnected/failed，
   重共享后不再转发；Failed 未清理重连）
   → 计划：SetICETimeouts keepalive + Failed 时 close 触发自动重连（未落地即决定移除）。

## 四、移除后影响

- 多主机互联 / 跨主机观看 / 跨节点聊天文件：不再支持。
- 单机功能全部保留：共享（屏幕/摄像头/音频）、观看、聊天、文件、远程控制、
  TURN 中继（浏览器跨网兜底）、穿透检测提示、防火墙自动放行（TeaShare-app/7553/3478）。
- 保留字段：enterHost（卡片"主机"显示）、myHostName（服务器主机徽章）、serverStart。
